Futures Report Project Guide

A data pipeline for downloading, extracting, and analyzing CFTC Commitments of Traders (COT) report data for E-Mini S&P 500 futures.

This project automates the full workflow of obtaining weekly CFTC Traders in Financial Futures (TFF) reports, filtering for E-Mini S&P 500 futures contracts, converting the data to a typed Parquet file, and performing analysis using Polars.

What is the COT Report?

Every Friday at 3:30 PM ET, the CFTC publishes the Commitments of Traders report reflecting positions as of the prior Tuesday close. It breaks down open interest by trader category: Dealers, Asset Managers, Leveraged Money, and Other Reportables.

save_futures.py

Step 1 Downloads CFTC financial futures data archives from 2020 to 2025.

What it does

  1. Creates a cftc_data/ directory if it doesn't exist
  2. For each year (2020–2025), downloads fut_fin_txt_{year}.zip from cftc.gov
  3. Extracts the zip — each contains a file named FinFutYY.txt
  4. Renames the extracted file to cftc_data_{year}.txt
  5. Cleans up zip files after extraction

extract_e_mini.py

Step 2 Filters the raw CFTC data to extract only E-Mini S&P 500 rows.

What it does

  1. Iterates through all cftc_data_*.txt files in sorted order
  2. Writes the CSV header from the first file
  3. For each row, checks if it contains "E-MINI S&P 500" and not "MICRO"
  4. Matching rows are appended to e-mini-sp500-futures.txt

Filter logic

SEARCH_TERM = "E-MINI S&P 500"

if SEARCH_TERM in line and "MICRO" not in line:
    f_out.write(line)
Why exclude MICRO?

The CFTC data also includes Micro E-Mini S&P 500 contracts (1/10th the size). The filter ensures only the standard E-Mini contracts ($50 × S&P 500 index) are captured.

FileDescription
e-mini-sp500-futures.txt~304 weekly rows of E-Mini S&P 500 COT data (2020–2025)

script/save_futures_report.py

Step 3 Parses the filtered CSV into a properly typed Polars DataFrame, then saves as Parquet.

What it does

  1. Reads e-mini-sp500-futures.txt with Polars
  2. Identifies which string columns are actually numeric by checking against a known set of text columns
  3. Casts columns containing "Pct" or "Conc_" to Float64
  4. Casts all other numeric columns to Int64
  5. Parses the date column and creates date, time (datetime), and sym columns
  6. Saves the result as futures_report.parquet

Column type logic

# Columns kept as strings
TEXT_COLUMNS = {
    "Report_Date_as_YYYY-MM-DD",
    "Market_and_Exchange_Names",
    "CFTC_Contract_Market_Code",
    ...
}

# Float keywords → Float64
FLOAT_COLUMN_KEYWORDS = ("Pct", "Conc_")

# Everything else numeric → Int64

study/study.py

Step 4 Exploratory analysis notebook for studying dealer/fund positioning trends.

What it does

  1. Loads futures_report.parquet via the custom Df.load_data_single helper
  2. Joins stock close price data with df.add_stock('close')
  3. Computes monthly aggregations of dealer short positions
  4. Groups by symbol and month for cross-instrument comparison

Example queries

# Monthly average dealer short positions
ds.group_by(pl.col("time").dt.truncate("1mo")).agg(
    pl.col("Dealer_Positions_Short_All").mean()
)

# Grouped by symbol + month
ds.group_by([
    pl.col("sym"),
    pl.col("time").dt.truncate("1mo")
]).agg(
    pl.col("Dealer_Positions_Short_All").mean()
).sort([pl.col("sym"), pl.col("time")])

Data source

All data originates from the CFTC's public Commitments of Traders (COT) historical data archive at cftc.gov/files/dea/history/. The specific report type is the Traders in Financial Futures (TFF) report.

Column Reference

The dataset contains ~86 columns. Here are the key groups:

Identification

ColumnTypeDescription
Market_and_Exchange_NamesStringe.g., "E-MINI S&P 500 STOCK INDEX - CHICAGO MERCANTILE EXCHANGE"
Report_Date_as_YYYY-MM-DDDateTuesday position date
Open_Interest_AllInt64Total open interest (all traders)

Position Columns (by trader category)

Each category has Long, Short, and Spread variants:

PrefixTrader Category
Dealer_Positions_*Swap dealers (banks, market makers)
Asset_Mgr_Positions_*Institutional investors (pensions, funds)
Lev_Money_Positions_*Leveraged money (hedge funds, CTAs)
Other_Rept_Positions_*Other reportables
NonRept_Positions_*Non-reportable (small traders)

Change Columns

Prefixed with Change_in_* — week-over-week change in each position category.

Percentage Columns

Prefixed with Pct_of_OI_* — each category's share of total open interest. Cast to Float64.

Concentration Columns

Prefixed with Conc_Gross_* / Conc_Net_* — position concentration ratios for top 4 and 8 traders. Cast to Float64.

How to Run

Full pipeline (from scratch)

# Step 1: Download all CFTC data (2020–2025)
python save_futures.py

# Step 2: Extract E-Mini S&P 500 rows
python extract_e_mini.py

# Step 3: Convert to typed Parquet
python script/save_futures_report.py

# Step 4: Run analysis (interactive / notebook)
python study/study.py
Important

Steps must be run in order. Each script depends on the output of the previous one. Step 1 requires an internet connection to download from cftc.gov. Step 3 requires the cyc custom package to be installed.

If data is already downloaded

If cftc_data/ already has the yearly text files, skip Step 1:

# Skip download, start from filtering
python extract_e_mini.py
python script/save_futures_report.py

If Parquet already exists

Jump straight to analysis:

python study/study.py
